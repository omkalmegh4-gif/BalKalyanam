> **BalKalyanam** is a compassionate digital platform built to support the children and operations of **Sada Shanti Balgruh** orphanage home. It bridges the gap between generous donors, volunteers, and children in need of care, education, nutrition, and love.

---

## 🌟 Key Features

- **🏡 Life at Sada Shanti**: Rich visual chronicles, photo galleries, and authentic stories highlighting the children's daily routines, education, creativity, and milestones.
- **🎁 Targeted Contribution Channels**:
  - **🍲 Nutrition & Food**: Meal sponsorships and ration support drives.
  - **👕 Clothing & Essentials**: Seasonal attire and daily wear coordination.
  - **📚 Education & Mentorship**: School supplies, books, tutoring, and skill development support.
  - **🤝 Volunteer Portal**: Flexible registration for mentors, event coordinators, and weekend volunteers.
- **📝 Online Registration & Inquiries**: Easy-to-use registration flows for donors and community advocates.
- **📱 Responsive Single-File Architecture**: Fast-loading, lightweight, and accessible on smartphones, tablets, and desktops alike.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Semantic Structure
- **Design & Icons**: Font Awesome 6.5.2, Custom Modern CSS3 (CSS Variables, Flexbox, Fluid Grids)
- **Interactions**: Vanilla JavaScript (Interactive tab navigation, modal dialogues, smooth scrolling)

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/omkalmegh4-gif/BalKalyanam.git
cd BalKalyanam
```

### 2. View in Browser
Open `index.html` (or `web.html`) directly in your web browser:
```bash
# Direct launch or via Python server
python -m http.server 8000
```
